# Evaluasi Pekan 6 - JavaScript

## Deskripsi
Proyek latihan JavaScript tentang pembersihan data transaksi,
mesin kasir, laporan harian, function, array, perulangan,
perbaikan bug, dan eksperimen JavaScript.

## Penulis
Ahmad Maulana

## Struktur Proyek
- index.html dan script.js: data, mesin kasir, laporan harian.
- logika.html dan logika.js: latihan logika.
- perbaikan.html dan perbaikan.js: perbaikan bug.
- eksperimen.html dan eksperimen.js: eksperimen JavaScript.
- .gitignore: mengabaikan file tertentu dari Git.

## Cara Menjalankan
1. Buka folder proyek di VS Code.
2. Buka index.html menggunakan browser.
3. Tekan F12 lalu pilih Console.
4. Untuk latihan lainnya, buka logika.html,
   perbaikan.html, atau eksperimen.html.

## Teknologi
- HTML
- JavaScript
- Git dan GitHub

## Pertanyaan

### 1. Kenapa pekerjaan dibagi ke banyak branch?
Branch memisahkan pekerjaan agar setiap bagian dapat dikerjakan
dan diperiksa tanpa langsung mengganggu main.

### 2. Apa fungsi .gitignore?
.gitignore mencegah file tertentu ikut dilacak oleh Git.
Pada proyek ini, node_modules/ dan .env diabaikan.

### 3. Apa beda merge lokal dengan Pull Request?
Merge lokal menggabungkan branch melalui Git di komputer.
Pull Request diajukan di GitHub agar perubahan dapat diperiksa
sebelum digabungkan ke branch utama.
